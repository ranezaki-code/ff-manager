## 1. 守る条件

前提：「急ぐ順」の新しい画面がオンの店。5.36 と違ってよいのは「印を時間で消さない」事と、下の「決まっている事」だけ。

### 決まっている事（変えない）
- 朝3時に印を外し、押し忘れ1件にする（下の表の6のとおり、書くのは朝3時の後の最初の記録の時）
- 別の人が取れる時刻の後は、印を消さず「⏳ 長い ◯件」にたたむ。作業は急ぐ順に戻る
- 目標の2倍をすぎて ✓ で延びた作業は、⏱ 平均から外す。記録は残す
- 急ぐ順の並びは、タブが最優先。おくれが別のタブに隠れないよう、タブの名前におくれの数を出す（読むだけ。保存しない）

並びを変えても、下の表の2（どの作業が、いつ、おくれ・もうすぐ になるか）は変えない。変わるのは順番だけ。

### 5.36 からある形（穴ではない。直すなら別の話）
- 目標が長い作業は、線まで別の人が取れない（60分→120分）
- 全部 ✓ の押し忘れは、別の作業の記録でも最後の ✓ の時刻で済になる
- 電波なしで同じ印を押すと、終わったと押し忘れが並ぶ（📊 は押し忘れを数えない）
- 前の画面の店の「今いる人の列」のスイッチは、押しても画面が変わらない

### 作り直す人への注意
試験を通すだけでは足りなかった。5.36.2〜5.36.5 の × は、どれも当時の wstest の全行が ○ のまま出た。**5.36 と1分ごとに比べる道具**を先に作ると、早く見つかる。継ぎ足しを4回した後、線を 5.36 の式1つに戻した（5.36.5）ところで大半が消えた。

## 3. 試験の場所と流し方

- WS：`v2/wstest.html`。FF：`v2/fftest.html`（83行）。どちらもブラウザで開くだけ。結果は画面の `#sum` と表に出る。人は作り物、保存先は `V2.MemoryCloud`
- 外へ出ない使い捨てのブラウザで開く（Firebase と Google のスクリプトの読みこみだけが出ようとするので止める）
- WS は6つの時刻で流す：02:30／06:00／10:00／14:00／18:30／23:30（`Date` を差しかえて）
- 行数：5.36＝301、5.36.5＝330（どちらも ×0）。5.36.6 は 97y を足した途中で、全時刻は流し終えていない
- **リポジトリだけでは wstest の全部は流せない。** 比べる相手の古い版のページ（`v2/wsold`・`wsold515`・`517`・`519`・`522`〜`526`・`5271`・`528`〜`531`・`533`・`536` と、上の `wsold`）が git に無い。`wsold536` は `git show e65c7c3:v2/ws/index.html` で作れる。全部そろった場所はこちらにあるので、全体の確かめはこの部屋のテスが受け持つ
- 5.36 の試験に足した場面（5.36.6 の写しの `v2/wstest.html`）：`97r1〜r6`（7171行〜）、`97s1〜s9`（7290行〜）、`97w1〜w8`（7463行〜）、`97x1〜x6`（7601行〜、`97x4` が 5.36 と1分ごとの比較）、`97y1〜y10`（5.36.5 の × の形）
- 点検の道具（1分ごと比較・ランダム・わざと壊した版・2台と古い版）は公開していない。全体の確かめの担当が持っている

## 4. ファイルの関係

| 直す所 | 作り直す | 試験 |
|---|---|---|
| `ws/index.html` | `bash v2/build-ws.sh` → `v2/ws/index.html` | `v2/wstest.html` |
| `ff/index.html` | `bash v2/build-ff.sh` → `v2/ff/index.html` | `v2/fftest.html` |

- 店で使う画面は `v2/` の入口（`v2/index.html`）から開く `v2/ws/`・`v2/ff/`。**`v2/ws/`・`v2/ff/` を手で直さない。** 道具は決まった差し替えだけをして写す
- e65c7c3 で両方の道具を流し直し、できた物が git の物と同じ SHA1 だと確かめた（2026-11-02）
- ⚙ の画面は `v2/index.html` で、道具では作らない。手で直す
- 改行は LF。`m4.html`・`v2/ffwindow.html` は公開に入れない
- 公開は店長の返事の後。入れるのは変えたファイルだけ

### FF の投資期間（WS の頼みの外。別に頼む時の覚え書き。WS の直しでは FF にさわらない）
- 今の入れ方は2つ：今週のマス目 `S.weeks[週].invest`（その週だけ）と、毎週効く設定 `S.budget.investCounts`・`investDays`（曜日は選べるが、期間は無い）
- 数を決めるのは `getInvestExtra0`。`investKind`・`investLegacyKind` も同じ判定を見る。作成表と予算の金額は同じ関数から数を取る
- 作った後のマスは `investDone` で数を固定している。期間を足しても、この数を動かさない
- 商品の販売期間は `prodOnDay` で別にある。保存の形は足すだけ
- 入口は「📈 今週の投資」。「⚙️ 投資・設定」の表は、印か今週の数がある商品しか出ないので、ハッシュドポテトが出なかった理由の候補。あわせて直すかは店長に確かめる
